# Gully Stars ⚽

A full-stack sports community platform built with FastAPI + React.

##  Quick Setup 

### Backend
cd backend  
python -m venv venv  
venv\Scripts\activate  
pip install -r requirements.txt  
python seed.py  
uvicorn app.main:app --reload  

### Frontend
cd frontend  
npm install  
npm run dev
